# Aviator Predictor App

A modern React dashboard for exploring Aviator-style analytics, probability patterns, live metrics, and prediction insights.

## Features

- Live dashboard with key metrics
- Trend chart comparing actual vs predicted multipliers
- Prediction engine with custom analysis parameters
- Risk and confidence analysis
- Mobile-responsive layout
- Clean dark interface

## Stack

- React
- Recharts
- CSS modules style system

## Getting started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

Then open http://localhost:3000.

### Build production bundle

```bash
npm run build
```
